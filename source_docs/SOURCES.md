# S&A Budget Source Documents

This folder contains the original public Seattle Central College Student Services and Activities (S&A) Fee budget documents used in this project.

The source PDFs are preserved as reference evidence so that extracted and processed budget data can be traced back to the original published documents.

## Source Files

### 2023–24 S&A Fee Memo

* **Local file:** `2023-24_sa_fee_memo.pdf`
* **Source:** Seattle Central College Student Leadership
* **Original URL:** https://studentleadership.seattlecentral.edu/sites/studentleadership.seattlecentral.edu/files/2023-09/2223-SA-Fees-Memo.pdf
* **Primary data represented:** 2022–23 allocation, 2023–24 request, and 2023–24 allocation
* **Notes:** Original source for the 2023–24 S&A budget recommendation.

### 2024–25 S&A Fee Memo

* **Local file:** `2024-25_sa_fee_memo.pdf`
* **Source:** Seattle Central College Student Leadership
* **Original URL:** https://studentleadership.seattlecentral.edu/sites/studentleadership.seattlecentral.edu/files/2025-01/2024-25%20Student%20Services%20and%20Activities%20Fees%20Memo.pdf
* **Primary data represented:** 2023–24 allocation, 2024–25 adjustment request, and 2024–25 allocation
* **Notes:** 2024–25 was part of a biennial budget cycle, so the request column should not automatically be interpreted as a full annual funding request.

### 2025–26 S&A Budget Summary

* **Local file:** `2025-26_sa_budget_summary.pdf`
* **Source:** Seattle Central College Student Leadership
* **Original URL:** https://studentleadership.seattlecentral.edu/sites/studentleadership.seattlecentral.edu/files/2026-02/FY26_S%26A_Budget%20Summary_Final.pdf
* **Primary data represented:** 2023–24 allocation, 2024–25 allocation, 2025–26 request, and 2025–26 allocation
* **Notes:** Includes program changes and historical comparison fields useful for validating earlier documents.

## Data Integrity Principle

Original source documents are not modified to resolve inconsistencies.

If the same fiscal year or program is reported differently across documents, both source values will be preserved and the discrepancy will be documented separately before a value is selected for analysis.
