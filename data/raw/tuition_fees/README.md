# Tuition & S&A Fee Sources

This folder stores official tuition and fee schedules used to document the Services & Activities (S&A) fee.

## Coverage

- 2023–24
- 2024–25
- 2025–26
- 2026–27

The main S&A budget dashboard currently covers FY2023–24 through FY2025–26.

FY2026–27 is retained as current/future context and is not yet used in the main dashboard analysis.

## Research Purpose

These source documents are used to document:

- S&A fees by credit load
- the full-time student fee range
- the typical 15-credit S&A fee
- the maximum/capped S&A fee
- year-over-year changes in student S&A charges

## Methodology Note

S&A fees are documented separately from total tuition.

The fee is credit-based and reaches a maximum at the applicable credit cap. Resident and nonresident tuition totals may differ, while the S&A fee schedule should be analyzed independently.

All values entered into the manual dataset should be traceable to an official source document stored in this folder.
